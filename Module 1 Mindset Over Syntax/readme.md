## overview:

Programming মানে শুধু syntax জানা না, বরং problem কে logically analyze করে efficient solution বের করা। এই module এ শেখানো হয় কীভাবে vague problem কে ছোট ছোট অংশে ভাঙতে হয়, data flow বুঝতে হয়, এবং কোন পরিস্থিতিতে কোন data structure ব্যবহার করলে performance ভালো হবে। এখানে Array, Set, Algorithm এবং Big-O notation এর মাধ্যমে বোঝানো হয় কেন কিছু code fast আর কিছু slow। যেমন small data তে simple loop কাজ করলেও large-scale application এ optimized algorithm দরকার হয়। O(n) এবং O(n²) comparison এর মাধ্যমে performance impact বুঝানো হয়। Overall, এই module এর main goal হলো “coder” না হয়ে “problem solver” mindset তৈরি করা— যেন code লেখার আগে efficient চিন্তা করা যায়।
